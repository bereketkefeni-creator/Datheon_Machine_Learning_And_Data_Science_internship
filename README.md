# Task 1: Multi-Class Iris Classification

## Overview

This project implements and compares two supervised machine learning classifiers on the Iris dataset: Logistic Regression and Decision Tree.

The objective is to predict an iris flower's species from four numerical measurements.

## Dataset

The dataset contains measurements for three Iris species:

* Setosa
* Versicolor
* Virginica

Features:

* Sepal length
* Sepal width
* Petal length
* Petal width

Target: `species`

## Methods

The project includes:

1. Dataset inspection and quality checks.
2. Exploratory data analysis using Seaborn and Matplotlib.
3. Feature-target separation.
4. An 80/20 train/test split with stratification.
5. StandardScaler preprocessing for Logistic Regression.
6. Logistic Regression and Decision Tree training.
7. Model evaluation using accuracy, macro precision, macro recall, and macro F1-score.
8. Confusion matrix visualizations.
9. Investigation of Decision Tree complexity and overfitting.

Scikit-learn pipelines are used to keep preprocessing and model prediction consistent.

## Limitations

The Iris dataset is small and relatively clean. A single train/test split does not provide a complete picture of model generalization. Results on this benchmark should not be assumed to transfer directly to unrelated real-world datasets.

## Learning Outcomes

This project demonstrates a supervised classification workflow, including data inspection, exploratory analysis, preprocessing, model training, evaluation, and interpretation.
